# raul-devops-practica

**Autor:** Raúl

## Descripción

API REST de una tienda online desarrollada en Python con **FastAPI** y **Pydantic**. Permite registrar usuarios (clientes y administradores), gestionar productos (genéricos, electrónicos y de ropa) y crear pedidos comprobando el stock disponible. Los datos se guardan en memoria.

Este repositorio se usa en las prácticas 3.1 (Git y GitHub) y 3.2 (Docker).
